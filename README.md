# Embedded AI — Leaf Disease Classifier (MobileNetV3-Small)

7-class leaf disease classifier based on MobileNetV3-Small, trained on a PC,
optionally distilled/quantized, exported to ONNX, and deployed for inference
on a Raspberry Pi.

## Folder structure

```
Embedded_ai/
├── all_process.ipynb      # Design notes / scratch notebook (Pi setup, XAI discussion)
├── data/
│   ├── class_indices.json # Label index mapping used by inference scripts
│   ├── raw/                # (not committed) put the raw, per-class image folders here
│   └── data_split/         # train / val / test, generated by scripts/data_split.py
├── models/
│   ├── mobilenet_v3_small_7cls.pth            # Trained teacher weights
│   ├── mobilenet_v3_small_7cls_distilled.pth  # Distilled student weights
│   └── leaf_model_fp32.onnx                   # ONNX export used on the Pi
├── scripts/
│   ├── data_split.py                    # raw images -> data/data_split (train/val/test)
│   ├── train_mobilenet_v3_small.py      # Train the teacher model
│   ├── distill_mobilenet_v3_small.py    # Distill a student model from the teacher
│   ├── zip_transform_model_to_onnx.py   # Export .pth -> ONNX (FP32, optional INT8)
│   ├── test_mobilenet_v3_small.py       # Evaluate the .pth model on data/data_split/test
│   ├── test_onnx_fp32.py                # Evaluate the ONNX model, also provides pick_test_images()
│   └── rasp_auto_check.py               # Runs ON the Raspberry Pi (capture -> infer -> email alert)
├── xai/
│   ├── xai_gradcam.py           # Grad-CAM
│   ├── xai_gradcam_standard.py  # "Standard" Grad-CAM variant
│   └── outputs/                 # Generated heatmaps/overlays + saved SHAP arrays
└── archive/
    └── another_demo/    # Earlier exploratory scripts (38-class scaffolding), superseded by scripts/ and xai/
```

## Pipeline order

1. Put raw, per-class-folder images under `data/raw/`.
2. `scripts/data_split.py` — splits into `data/data_split/{train,val,test}`.
3. `scripts/train_mobilenet_v3_small.py` — trains the teacher, saves to
   `models/mobilenet_v3_small_7cls.pth`.
4. `scripts/distill_mobilenet_v3_small.py` (optional) — distills a student
   model into `models/mobilenet_v3_small_7cls_distilled.pth`.
5. `scripts/test_mobilenet_v3_small.py` — sanity-checks accuracy on the
   `.pth` model.
6. `scripts/zip_transform_model_to_onnx.py` — exports the trained `.pth` to
   `models/leaf_model_fp32.onnx` (and optionally an INT8 ONNX; INT8 export
   must run on Linux/macOS, not Windows).
7. `scripts/test_onnx_fp32.py` — sanity-checks the exported ONNX model.
8. `xai/xai_gradcam.py` / `xai/xai_gradcam_standard.py` — generate Grad-CAM
   heatmaps/overlays into `xai/outputs/`.
9. `scripts/rasp_auto_check.py` — deployed and run directly on the Raspberry
   Pi (uses absolute `/home/pi/leaf_checker/...` paths, independent of this
   repo layout).

All scripts locate the project root relative to their own file location
(`os.path.dirname(os.path.abspath(__file__))`), so they can be run from any
working directory — just `python scripts/train_mobilenet_v3_small.py`, etc.
The two `xai/*.py` scripts import `pick_test_images` from
`scripts/test_onnx_fp32.py` and add `scripts/` to `sys.path` for that.

## Notes

- `all_process.ipynb` is a working notebook of Raspberry Pi setup notes and
  XAI feasibility discussion (LRP/SHAP ruled out as too heavy for the
  device; Grad-CAM used instead) — it's not a runnable end-to-end pipeline.
- `archive/another_demo/` is kept for reference only; its scripts assume a
  different (38-class, MNIST-demo) setup and are superseded by `scripts/`
  and `xai/`.
- Key dependencies: `torch`, `torchvision`, `onnxruntime`, `numpy`, `pillow`.
